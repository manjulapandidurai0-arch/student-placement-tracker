# Student Placement Tracker

A Python-based desktop application that helps students track their job applications, companies, job roles, and application status.

## Project Overview

The Student Placement Tracker is designed to make job application tracking simple and organized. Users can enter company details, job roles, and application status through a user-friendly graphical interface.

## Features

- Add company name
- Add job role
- Track application status
- Display applications in a table
- Store application data using SQLite
- Simple and user-friendly GUI

## Technologies Used

- Python
- Tkinter
- SQLite
- VS Code

## Application Status

The application supports the following statuses:

- Applied
- Shortlisted
- Interview
- Selected
- Rejected
